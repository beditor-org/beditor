## CSS

install tailwind cli:

```
curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-linux-x64 && chmod +x tailwindcss-linux-x64 && ./tailwindcss-linux-x64 --version
```

run it in watch mode

```
./tailwindcss-linux-x64 -i assets/tailwind.css -o assets/tailwind-compiled.css --watch
```
